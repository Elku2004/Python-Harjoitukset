# Solve The Mystery
Pelissä, sinun tehtäväsi on palata kaupunkiin ja selvittää, kuka on veden pilaamisen takana.
Keräät todistusaineistoa, jotka vaikuttavat siihen, kuinka peli loppuu.

Pelissä on 3 tasoa jotka voi pelata. Kun on suorittanut pelin, voi yrittää aiempia tasoja uudelleen

Pelin voi tallentaa ja jatkaa siitä, mihin aiemmin jäi
